# Forestry Domain Pack

Status: **EXPERIMENTAL 0.2.0 — synthetic data only**

This pack defines TreeRecord, InspectionRecord and Site, with six synthetic
trees, six inspections and two sites. The three CSV files are the record inputs;
the JSON and TXT files explicitly declare synthetic provenance and limitations.
The mapping declaration is data, not executable Python/Shell. OWL, SHACL and a
nonempty read-only CQ Oracle are included for actual toolchain validation.

No field trial, real coordinates, expert signature, department decision, legal
age threshold, diagnosis, risk prediction, OCR or ASR result is asserted.
The previous planning-only 0.1.0 pack is preserved in Git history. Exact 0.1.0
resolution is unavailable in this single-version checkout, never silently
rebound to 0.2.0. Pack validation alone does not prove a full workflow.
