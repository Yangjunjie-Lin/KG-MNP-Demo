artifact for compiler 0.5.0. It fixes the 25 Prompt 4 candidate types, overlay
module semantics, local locked baselines, statement provenance, OWL 2 DL,
pinned HermiT, offline SHACL Core, registered CQ oracles, strict packaging,

never infinity. A policy identity mismatch fails before a plan is created.
