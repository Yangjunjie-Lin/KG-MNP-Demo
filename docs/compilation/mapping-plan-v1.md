# Declarative MappingPlan v1

All six confirmed Mapping kinds become sorted inert JSON records with their
KG-IR/evidence, target, conversion/null policy, dependency, review and
provenance references. Templates accept only simple named placeholders; code,
attribute access, calls, shell/Python and SPARQL Update are rejected. The plan
is packaged but never executed by Prompt 5. Null and missing policy remain
explicit rather than inferred.
