# OWL 2 DL Consistency

The Stage 03 root/runtime ontology and the compiled ABox are checked with the
checksum-pinned ROBOT 1.9.7 distribution and its HermiT dependency. The package
report records the release hash, ABox hash, combined-input hash, tool hashes and
exit status. Only `CONSISTENT` is a passing result. Stage 06 never updates the
tracked Stage 03 reasoner attestation and never materializes inferred facts.
