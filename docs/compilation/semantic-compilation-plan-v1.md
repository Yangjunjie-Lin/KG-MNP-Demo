# Semantic Compilation Plan v1

The plan binds attestation, confirmed package, compiler snapshot, explicit
package/ontology version and IRIs, locked baseline assets, one dispatch record
for every confirmed candidate, named graph roles, exact formal profiles,
finite limits, expected artifacts, and 17 ordered operations. It writes no RDF.
Unsupported types or action/partition mismatches make planning fail closed.
There is no automatic SemVer decision or bump.
